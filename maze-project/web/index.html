MazeMind Assessment Lab

Adaptive maze generation using backtracking for cognitive skill assessment. Every test maze is created fresh by a recursive backtracker, so it can't be memorised, and its difficulty adapts to how the person performs.

The real-world problem

      
Maze tests such as the Porteus Maze Test are used by psychologists to measure planning and foresight in children, in people with ADHD and in older adults showing signs of dementia. Printed tests have a fixed set of mazes, so people who take the test again can remember them, and the difficulty steps are coarse.

      
MazeMind generates a new maze for every trial with a recursive backtracker, measures its difficulty, and changes the next maze's size based on how the person did. That gives unlimited, comparable test items.

      
How it works

      
    
        
  1. Generate. A randomised depth-first search carves passages from the top-left cell. When it reaches a dead end it backtracks to the last cell that still has unvisited neighbours. The result is a perfect maze: a spanning tree of the grid with exactly one route between any two cells.
    2. 
        
  2. Measure. BFS finds the shortest route L. Every cell on it that offers two or more new exits is a decision point J. Difficulty = L + 3J.
    3. 
        
  3. Calibrate. For each trial, 9 candidate mazes are generated and the one with median difficulty is used, so trials at the same level are equally hard.
    4. 
        
  4. Score. Path efficiency (shortest moves ÷ moves taken), wrong turns (steps off the correct route), planning time (time before the first move) and wall bumps.
    5. 
        
  5. Adapt. A staircase rule moves up a level after a clean solve (no wrong turns, efficiency ≥ 85%) and down after a poor one (3+ wrong turns or efficiency below 50%).
